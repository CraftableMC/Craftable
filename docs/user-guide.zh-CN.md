# 用户指南 — Craftable（配方书）

[English](user-guide.en.md) · [文档导航](README.md) · [模组介绍](../README.zh-CN.md)

Craftable 使用当前工作环境中的可用材料，递归准备中间物品并完成普通原版合成。它增强原版配方书，不增加存储网络、新方块或科技树。游戏内功能名为“配方书”（英文 Recipe Book），模组列表中的名称为 Craftable。

## 安装与兼容

目前提供 **Minecraft 1.21.1 NeoForge** 版本，运行需要 Java 21。Fabric 和其他版本正在制作中。

把对应 JAR 放进游戏实例的 `mods` 文件夹，重启就可以了。多人游玩时，服务端和客户端要用同一份构建；升级前记得备份存档和配置。想自己从源码构建的话，可以看[开发指南](developer-guide.zh-CN.md)。

## 快速上手与能力按键

准备一些原料，放在主背包或附近可用容器中，再打开背包或工作台的配方书。
背包默认是 2×2；需要 3×3 时，在附近放一个可用工作台就行。

鼠标放在想做的配方上：

| 操作 | 结果 |
| --- | --- |
| 按 C | 尝试完整合成一批。比如一次配方会出四块木板，得到的也是四块。 |
| 材料不足时对同一配方双击 C | 请求部分准备。首击仍先尝试完整合成，两次按下之间需要松开；单次失败或长按不会自动消耗一部分材料。 |
| Shift+C | 打开详情，看看物品链。点击目标或中间节点选择做法，还可以调整最终材质和合成次数/MAX。点击“合成”才会请求制作。 |
| 左键 | 已解锁的普通配方能放进当前合成格时，照常用随身材料填格或显示虚影。炉类配方、尚未解锁或放不进当前合成格的配方会打开详情。想从附近容器取料就按 C。 |

默认制作键是 C，可以在原版控制设置中修改；Shift 跟随重新绑定后的制作键。聊天和搜索输入不会被制作键抢走。

增强配方书移除了原版右键小窗。详情的配方卡会画出合成格或加工前后的物品，并写明这条路线需要什么工作站。

另外，界面比较窄时，原版配方书会盖住一部分背包，而不是和背包并排显示。这里也尊重了原版的显示方式，没有改它。

### 配方颜色与右上角标记

配方会用颜色表示状态，提示里也会解释原因。颜色大致是这样（按肉眼观感说，不是严格的色卡名称）：

| 颜色 | 状态 | 解释 |
| --- | --- | --- |
| 绿色 | 可合成 | 当前显示的配方可以完整合成。 |
| 红色 | 不可合成 | 当前不能完整合成，具体原因看提示。 |
| 背景淡黄色 | 可部分合成 | 材料不足，但其中一些中间材料可以先做出来。 |
| 淡红偏粉色 | 同按钮里还有可合成的材质 | 比如栅栏：当前显示的材质不可合成，但这个按钮里的另一种材质可以。可以等它轮播过来，或在详情里手选。 |
| 白色／原版底色 | 没有结论 | 还没算出是否能合成，或暂时没有可用的结果。 |

右上角标记表示的是当前目标：

| 标记 | 含义 |
| --- | --- |
| `+` | 可以完整合成一批。 |
| `!` | 当前不能合成，原因见提示。 |
| `~` | 可以部分准备，或者正在刷新。 |
| `?` | 还没确定是否可合成，也可能到了这次计算的限制。 |

正在刷新不妨碍你继续尝试制作。页面可能先保留上一已知颜色，服务器会在真正制作前重新检查材料、空间和规则。计算中或未知，并不等于材料不足。

同一种成品有不同原料路线时，会选可行的路线；船、栅栏这种不同材质的成品，则按当前显示或你手选的材质制作。换了配方或最终材质，记得再看一眼整条链和用量。

另外，鼠标拿起的物品、当前 2×2/3×3 合成格里的物品，这里也会一起算进材料，不用特意放回背包。原版鼠标拿起的物品和 2×2 合成格里的物品，不算你拥有的材料，这里当作 bug 修掉了，没有严格尊重原版。

原版旁观者模式有个有点意外的地方：配方书可能还看得见，却不能操作。这里还是尊重原版的做法；创造和旁观者模式不启用这套合成能力。

## 炉类加工

合成链需要熔炼时，附近要有空闲的对应炉子和燃料。比如做铁镐时，铁锭不足也可以用粗铁接着做。

也可以直接在背包配方书里搜“铁锭”。同一成品的不同做法会归到同一个按钮里。选中炉类配方时，左键查看详情，按 C 开始加工。附近只有熔炉时，用背包里的 2×2 页面就可以操作。详情页左上角会显示当前可用的工作站。

点燃的空闲篝火和灵魂篝火也能烹饪食物，只需要生食。关闭时间压缩后，中途熄灭的篝火要重新点燃才会继续加工。

世界规则里的“炉类时间压缩”默认开启，材料齐全时和普通合成一样立即完成。关闭后，提交便扣除需要的材料和燃料。加工随工作站一起运行，关掉背包或工作台也会继续。把鼠标放在合成箭头或旁边的进度条上，可以看剩余时间、暂停原因，或查看是否待领取。

区块停止运行或工作站正在被手动使用时，加工会暂停。完成后成品和余料一起放进主背包，放不下就等你腾出空间。工作站在完工前被拆掉时，会把收取的材料和燃料退回背包。

## 哪些材料可用

- 主背包、当前 2×2/3×3 合成格及光标上的物品。
- 附近已加载、在范围内、能打开且有权限使用的原版方块容器。默认范围是水平 8 格、垂直 4 格，可以在世界规则里调整。
- 已放置且可用的潜影盒。
- 世界规则允许，且附近放着可用末影箱时，自己的末影库存。

阻挡、锁定、未生成战利品等限制仍然有效。
同一份材料不会因为一个容器有多个视图就算好几次。
带自定义名称、内容等非默认组件的物品，默认会受到保护，递归制作不会自动消耗它们。

## 哪些材料还不能用

有些还在开发中，有些本来就不作为普通材料，比如结果格和装备：

- 结果格、装备和副手里的物品。
- 随身潜影盒、收纳袋等物品内部的材料。
- 只在背包或附近放着末影箱“物品”时的末影库存访问；目前需要放置成方块。
- 地面掉落物和实体库存。
- 村民交易、生物交互（比如剪羊毛、挤牛奶）和世界互动的产物。比如某些模组把物品放进水里转换成另一种物品，这类专用加工目前也还不能直接接入。

白名单管理已支持配方的免确认规则。

## 数量、空间与部分准备

简单来说，“根配方”就是这条合成链最后想做的东西对应的配方。

数量表示根配方执行几次，不一定就是最后得到几个物品。
单次根配方次数默认最多 64，可以在世界规则里设为 1–64。
整条链还会单独数上根配方和中间步骤的实际执行次数，默认最多 128，可以设为 1–256。

最大可制作数量只有算清楚后才会显示精确最大值。
“至少”表示已经知道能做这么多，还可能做得更多。
提高步骤上限不会增加计算时间、内存或传输额度，所以复杂配方还是可能算不出精确上限。

成品必须放得进主背包。默认余料也要装下；只有世界允许、个人也没额外禁止时，放不下的余料才会掉落。

部分准备只做当前目标需要、规则允许的最少完整批次，不会顺便把所有原木都做成木棍。
比如钻石镐需要两根木棍，现在只有一块原木：条件允许时，会先做出四块木板，再用其中两块做出四根木棍，剩下的木板就留着，不继续做更多木棍。空间限制也还是要遵守。

### 四种部分合成模式

世界与个人设置里都是这四项，正常的完整合成不受它们限制：

| 模式 | 对明确请求的部分准备的影响 |
| --- | --- |
| 禁止部分合成 | 不执行部分方案。 |
| 全部需确认 | 可以查看部分方案，确认后才做。 |
| 白名单免确认 | 每个实际步骤都在世界白名单里时，可以免额外确认；名单外需要确认。 |
| 全部免确认 | 已支持且通过检查的部分步骤免额外确认，其他限制照常生效。 |

世界默认“白名单免确认”；
个人默认“全部免确认”，只是“不额外收紧世界”，不能覆盖服务器的禁止或确认要求。
两者按“禁止部分合成 → 全部需确认 → 白名单免确认 → 全部免确认”取更严格的一项。
个人白名单模式也用世界同一张名单，不另开一张个人名单。

白名单存的是完整**配方 ID**，不是成品物品 ID，因为同一种东西可能有不止一种配方，比如木棍可以用木板做，也可以用竹子做。
默认提供 32 项木板、木棍和部分存储转换配方。高级配置里可以直接编辑 ID：名单里免额外确认，名单外需要确认。
空名单表示所有部分准备都需确认，切换模式不会删掉名单。

名单最多 128 项，每个 ID 最多 128 字符。合法但未知或不支持的 ID 可以留着，暂时不生效。
数据包用同一个已列出的 ID 替换配方后，仍按这个 ID 判断免确认资格，但真正用料和产量会跟着数据包走。比如把木板制木棍的产量从四根改成两根，就会按两块木板一批出两根来算，不会继续当成四根。

白名单和“全部免确认”都不会绕过解锁、工作台、受保护物品、访问权限、空间和计算限制。

## 设置

在“选项 → 辅助功能设置”的可滚动列表里找到“配方书”，就能打开“配方书设置”。
主页有六项个人偏好：配方书增强、仅已解锁配方、详细失败提示、部分合成设置、丢出余料和双击间隔。

### 世界规则与白名单

- 单人世界没开放局域网、而且世界配置已经加载时，可以“编辑世界规则”。
- 远程服务器或已开放 LAN 时，世界规则页只读，包括远程 OP。个人偏好还能改，但只能收紧世界限制。
- 没进世界或配置还没加载时，普通世界编辑入口不可用。编辑途中换世界或开放 LAN，原页面也不能继续保存，得返回后重新打开。
- 只读页的“重新读取规则”会更新这页读到的规则，不是刷新合成预览的按钮。

只有“白名单免确认”模式能编辑“部分合成白名单”。普通名单页可以按物品名、物品 ID 或配方 ID 搜索，再切换“允许直接准备／需要确认”。结果太多就缩小一点搜索范围。目录加载中或暂时不可用，也不会把已保存的 ID 丢掉。

想精确增删 ID，或编辑还没识别出来的 ID，可以用 NeoForge“模组 → Craftable → 配置”，或“高级配置”。两种界面改的是同一套设置和世界名单。

### 设置的保存与取消

虽然听上去不可思议，这种事情也要说吗？不过涉及高级配置时还真有点复杂，还是解释一下。

普通可编辑页先改草稿：

- “完成”才保存；“取消”或 Escape 放弃本页草稿。
- “默认值”只重置草稿，还要点“完成”才会保存。
- 白名单子页的“完成”只回到世界规则草稿，父页还得点一次“完成”。父页取消，名单修改也一起放弃。
- 高级配置保存的更改独立生效，普通页“取消”不会撤销它们。从高级配置回来时，普通页已经改过的项目会保留草稿，没改过的项目会更新成高级页的新值。

配置变化后，等合成结果刷新，再看一下当前方案。

如果觉得这些看着有点复杂，就记住：想保留普通页的修改，返回时逐页点“完成”。

## 另外说明

配方书默认可以显示所有已同步的普通配方。想只看已解锁的，可以在个人设置里打开“仅已解锁配方”，不过这只是显示筛选，不会替你解锁配方。

如果想限制未解锁配方的制作，要用世界的配方解锁规则（`doLimitedCrafting`）；实际制作会遵守它。

## 限制与排错

| 情况 | 先检查 |
| --- | --- |
| 材料看得见却不能使用 | 容器范围、加载、阻挡和使用权限；是不是受保护物品；有没有可用工作台。 |
| 一直计算中，或只显示“至少” | 可以先试试较小数量。步骤上限不会增加计算时间。如果只是卡在计算限制上，这不是你的错，只是我（[@lewe189](https://github.com/lewe189)）暂时还没想到更好的计算方法。 |
| 名单内仍要确认 | 看看具体配方 ID、链里每个实际步骤，还有个人是不是选了更严格的模式。 |
| 世界规则无法编辑 | 检查是不是开放了 LAN、连接远端、还没进世界，或配置还没加载。 |
| 设置似乎未保存 | 看看父页有没有点“完成”；高级页保存和普通页取消是分开处理的。 |
| 原本可合成，现在被拒绝或要求重看 | 材料、空间、规则或权限可能变了，重新看一下当前方案。 |
| 不能加入服务器 | 核对游戏和加载器版本，以及两端是不是同一份 JAR。 |

反馈问题时，请带上游戏与加载器版本、JAR 身份或文件哈希、单人/远程/LAN、目标配方和材质、次数、材料放在哪里及数量、主背包空位、操作顺序、相关设置，再附上截图或带时间的日志。其他玩家的私有库存和敏感信息就别一起上传了。
