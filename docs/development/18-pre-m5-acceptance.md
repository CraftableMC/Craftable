## 4. 影响验收的失败与修正

- **完整确认入口。** `20261009-pre-m5-accessibility-planning-2/` 报 `Full confirm disabled`，未到设置场景；日志欠缺结果码/租约/预算，不能唯一归因，也不能认定新设置入口导致。后来 `20261010-pre-m5-stage7-audit/` 同版两次自然通过。`20261012-pre-m5-stage7-controlled/` 重现另一种明确路径：同值租约续期已可用，但 200 ms 只读节拍提前返回，按钮残留禁用。`20261012-pre-m5-stage7-fix/` 对照红/绿证实只补控件刷新；未放宽权限、节拍、预算或等待。
- **独立服务端审阅开销。** 上述按钮修复后自然回归仍出现本地 `CREATED`、服务端 `SEARCH_BUDGET_EXCEEDED` 无令牌；按钮禁用是正确结果。显式见证取证证明 3 步复验、零完整重搜，曾耗尽回放预算；首轮优化后无诊断运行仍失败，具体后段检查点未定位。最终消除重复步骤包装、集合/投影与栈副本开销，保留真实配方、来源、容量及原 8 ms 请求/16 ms tick 准入复验。最终同 JAR 在两个独立 JVM 均自然完整通过，无过滤、取证、租约注入、业务预热或预算重试，未通过扩大预算争取 PASS。按“修后未再出现暂视解决”处理按钮缺口和独立审阅问题；不证明旧失败唯一根因或任意负载的成功，超时仍应拒绝执行。

- **测试整理中的未明红例。** `20261021-084905-371-all/` 的物品换位 `Moved log disappeared/recolored`、`20261021-112211-503-all/` 的仅用箱内材料制作木棍时预算拒绝、`20261021-150123-861-all/` 的批量确认库存等待超时分别保留。后续独立组未再现，不说明根因已修复；批量样本 MAX 已证明 32，不能称为 MAX 求解失败。容量夹具在 `20261021-181537-038-baseline/` 和 `20261021-181725-107-baseline/` 可重复失败；确证附近其他夹具箱落入扫描区，未直接观测失败计划选箱。收紧**测试**半径隔离邻箱且恢复原配置后，两独立服务端组都通过。

## 5. 后续按需复测清单

下面是可复用操作，不是对任意新版 JAR 的勾选。选择受变更影响的条目；联机使用同一受测 JAR，记录哈希/协议、单人或专服/LAN、语言和缩放。用独立生存世界、备份配置和资源，无关容器不掺料，每项后还原材料、规则、名单和鼠标/网格库存。

### 基础设置和执行

- 中英分别打开辅助功能入口：末行优先填空右槽，满行另起左槽，无重复；原选项布局不挪动。窄窗口/缩放后检查搜索、滚动、Tab、方向键、Enter、旁白和退出。个人双列直接展示；普通可编辑 footer 为取消/默认值/完成，专业 Undo/Reset 保持框架语义。
- 改个人值与滑块后取消/Escape 不保存；默认值只改草稿，完成才写并重启保留。原版与高级页共用注册定义；从专业页返回保留普通页有意编辑的项目、刷新未改项目，普通页取消不撤销已保存的专业更改。
- 标题界面及 SERVER 未加载不伪显示或编辑世界规则；单人未开放 LAN 可编辑。真实专服和 LAN 主机/访客只读同一有效规则，远程 OP 或本地不同 SERVER TOML 不得覆盖；重读/完成并排，来源与状态可在提示/旁白读取。退出及换世界不残留旧规则。专业页跨生命周期回调单独按[受控技术验收](17-production-behavior-audit.md#lifecycle)。
- 普通设置不显示诊断缓存项。在高级页设为 0 后，验证只读诊断命令不再复用缓存，配方书与制作仍按新鲜环境检查。

### 物品链、数量与确认

- 分别设世界步数上限为 1、128、256，查看普通单步和含中间步骤的物品链。拖动数量、切换配方或成品材质后，核对当前目标的材料、产物与缺口。超预算或无法确定 MAX 时，界面应保留未知或「至少」的含义。
- 先取得可确认的详情，再改变步数、材料、目标或容量。确认旧预览、MAX 和令牌按新条件失效，拒绝时材料与产物不变。取消或换目标后，旧的排队操作不能发出。
- 在可复现的材料和容量条件下核对固定数量与 MAX。64 橡木原木应可做 32 箱。确认时重新校验收支。原来仅能在 128 步内做 42 箱的混材路线，复测时显式把世界设为 128 步。

### 部分合成与白名单

- 普通与专业页只各展示一项四态世界设置，个人显示同四态但无独立名单。仅白名单模式可编辑，切换进出保留内容；普通半宽按钮补末行空位。名单子页完成只合入父草稿，父页保存才落 TOML；默认值恢复预设，取消/搜索不写名单。专业编辑保留精确 ID、数量/长度/重复/格式校验。
- 用同一缺料目标核对世界×个人 16 组合和入名单/不入名单：取更严格者，个人白名单引用世界表；禁止与未知零部分消费，需确认必先审阅，白名单内/全部免确认只省额外确认。单 C 不部分消费，完整合成仍可做；旧方案/MAX/token 在模式或名单改动后失效，重读新规则或租约，不靠重启或重建静态目录才生效。
