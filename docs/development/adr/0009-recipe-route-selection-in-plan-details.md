# ADR-0009 — 在配方链详情中选择做法

- 日期：2026-11-21。
- 状态：已接受(尚在补充中，已接受部分已经实施)。
- 适用于 Craftable 增强的背包和工作台配方书。

## 背景

粗铁可以用熔炉或高炉加工成铁锭，铁锭也可以用铁粒合成。把这些做法归到一个配方书按钮后，原版右键小窗会用相同的合成格画出炉类配方，玩家难以区分这些路线。点选炉类路线打开详情时，原版小窗还可能盖在配方链上。让小窗同时适配炉类和更大的合成格，会产生两套路线选择和配方预览。

## 决策

1. 配方书继续承担搜索、浏览和快速操作。同一物品及组件的做法可以共用一个按钮，详情中的每条做法保留自己的配方 ID。即使投入和产物相同(如高炉和熔炉，只是工作站不同)，也各自显示所需工作站。
2. 移除增强配方书按钮的原版**右键**小窗。
3. **左键**改为按当前目标选择路线。已解锁且能放入当前菜单合成格的普通配方交给原版填格或显示虚影，其余路线直接打开与 **Shift+C** 相同的详情页。两种详情入口都携带按钮的成品变体，可在根节点选择。
4. 详情中通过目标和中间节点选择做法(这是明确的代替原版右键小窗的方案)。普通配方按实际所需合成格绘制，工作台 3×3 与随身 2×2 分别标明。熔炉、高炉、烟熏炉和篝火显示原料到产物的加工关系，以及当前路线所需的工作站。图左上角的可用工作站列表仍用于查看当前环境。
5. 未来的工作站需要明确的预览定义。没有可识别图样时，可展示现有的配方信息，或告知暂无图样。更大的网格和新工作站独特的配方样式要有单独的执行支持，才能参与自动合成。

## 执行边界

打开详情或选择做法只更新预览意图。确认时服务端按所选配方及当时的工作站、材料、权限和容量复验。现行预览和确认边界见 [ADR-0008](0008-snapshot-scoped-client-planning.md)。

配方书前端和合成格预览沿用原版交互及真实菜单尺寸约束。见 [ADR-0001](0001-vanilla-recipe-book-frontend.md) 和 [ADR-0005](0005-m3-recipe-book-and-menu.md)。

## 代价

明确改动了原版的内容，没有完全尊重原版。

## 明确否定的代替方案

- 修改原版右键小窗表现：空间太小，难以正常显示，恐怕遇到 4x4 的配方就会直接无法调和。
