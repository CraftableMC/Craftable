# M5 验收与测试记录

M5 仍在实施。本文先收录验收条目、已执行的验证和当前待解决的问题。实现与范围见 [M5 实施计划](19-m5-implementation-plan.md)，运行方式见 [测试说明](../../tests/README.md)。

## 1. 验收条目

1. **静态配方预热。** 在生存或冒险模式进入世界，尚未打开背包时静态目录已就绪。首次浏览使用同一代目录。核对目录构建中断、配方或标签世代切换、超限以及专服正常保存和重启恢复。
2. **熔炉与铁镐链。** 把粗铁、原木和燃料分开放置，在熔炉和工作台附近制作铁镐。核对扣料来源、成品、余料和经验。分别用错误工作站、缺燃料、背包容量不足和审阅后移走炉或燃料测试拒绝路径。开工前拒绝时，材料、产物和经验均应保持原状。
3. **专用炉与批量。** 高炉和烟熏炉各用正确的工作站和燃料折算。多件和 MAX 计入燃料以及整链的计时加工批量上限，按原入口审阅和提交。提交中途失败应恢复已扣材料。湿海绵分别走默认烘干和接水路线。后者复测空桶加燃料及单只熔岩桶两种投入，核对桶的收支。
4. **切石、锻造和酿造。** 配方书能搜到三类成品，详情中能找到对应工作站和路线。核对切石产量、下界合金升级的三项投入、水瓶到迅捷药水的多步耗材，以及用龙息转换后的玻璃瓶返还。检查护甲纹饰和带非默认组件的装备仍由原版流程处理。
5. **配方链与配方书。** 羊毛路线能跳过重复染色，保留线制羊毛和指定颜色，多件缺料时给出正确缺口。铁矿和燃料够时，铁裤腿走七次熔炼加一次合成。只有熔炉时，背包的「仅可合成」仍能搜到铁锭。相同成品只占一个按钮，在详情的节点选配方时仍可区分不同工作站，图样与工作站一致。
6. **计时订单。** 关闭加工时间压缩，分别在原版 2×2、临时背包 3×3 和实体工作台查看进度。关界面再打开，检查进度继续。离开到工作站所在区块停止运行，回来检查从暂停处继续。填满主背包后等待「待领取」，再腾位置核对成品和余料。分别在加工中和完工待领取时拆除工作站，核对退料与保留成品的区别。营火熄灭后重新点燃，以及手动占用工作站后腾空，也要能恢复计时。

## 3. 当前阻塞和待改进项

- **锻造模板的递归复制。** 模板既是复制配方的原料，也是成品。以下界合金剑为例，有一份模板且其他材料足够复制时，规划应能先复制再升级，完成后至少留下一个模板作为种子。没有模板时仍应报告实际缺口。此项待修复并补回归。
- **Shift+C 选配方界面。** 当前页面能选路线并显示图样和所需工作站，界面仍比较简陋，安排在本阶段继续调整。
- **描述和提示。** 部分新文案偏工程化，待结合游玩继续调整。

### 当前实现取舍

- 营火和灵魂营火的配方能力相同，共用一个工作站图标。
- 一个计时订单对每种炉型只绑定一台。后续可按件分配给多台炉子，工作站拆除后的重新分配也按件考虑。营火的多槽烹饪和酿造台的多瓶并行暂未接入。
- 同一个工作站不能同时接两份计时订单。玩家仍可手动使用它，手动占用期间订单暂停。后续考虑改成锁定被使用的工作站，只读并提示被占用了。
- 熔炉有原版余火时暂不可接单。空闲酿造台剩余的原版燃料用量由原版管理。模组计量的余火和酿造余量只在同一订单内共用。后续再讨论是否退回尚未使用的燃料，以及能否保留余量供下次使用。
