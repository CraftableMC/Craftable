# Craftable Icon Assets

## English

- `craftable-icon-source-20x18.png`: 20×18 original pixel artwork, adapted from the vanilla Minecraft recipe book icon by removing the background and adding a double-layered golden upgrade arrow.
- `craftable-icon-1000-transparent.png`: 1000×1000 transparent icon, enlarged 40× using nearest-neighbor interpolation and centered with transparent padding.
- `craftable-avatar-500.png`: 500×500 avatar version with a light-colored background.

The mod uses `src/main/resources/icon.png` as its icon. Its content is identical to `craftable-icon-1000-transparent.png`.

**Editing:** Modify the 20×18 original pixel artwork and regenerate the high-resolution assets. Avoid using the small original directly as the mod's display icon, as in-game scaling will cause the image to become blurry.

**Attribution:** The original recipe book artwork comes from Minecraft. The associated intellectual property rights belong to Mojang Studios and Microsoft.

## 简体中文

- `craftable-icon-source-20x18.png`：20×18 原始像素图，基于 Minecraft 原版配方书图标修改，移除背景并添加双层金色升级箭头。
- `craftable-icon-1000-transparent.png`：1000×1000 透明图标，使用最近邻插值放大 40 倍，并通过透明留白居中。
- `craftable-avatar-500.png`：500×500 浅色背景头像版本。

模组使用 `src/main/resources/icon.png` 作为图标，其内容与 `craftable-icon-1000-transparent.png` 完全一致。

**编辑说明：** 请修改 20×18 原始像素图，并重新生成高清资源。避免直接将小尺寸原图作为模组展示图标，因为游戏内缩放会导致图片模糊。

**素材归属：** 原始配方书图案来自 Minecraft，相关知识产权归 Mojang Studios 和 Microsoft 所有。
